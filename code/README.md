# Quill K1

A keyboard phone you can use in the browser: messages, contacts, calls, calendar, memos, a clock and three games.

## Put it on GitHub Pages
1. Create a new repository on GitHub and upload `index.html`, `style.css` and `script.js` to the root.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your phone is live at `https://<your-username>.github.io/<repo-name>/`.

## Controls
- Trackpad: swipe to move, click to select (arrow keys + Enter on a computer)
- Green key: open phone / answer a call
- Red key: hang up / go home
- Menu (Tab) and Back (Esc)
- Type on the on-screen keys or your own keyboard. `alt` types the small numbers and symbols.

Data you add is saved in your browser's local storage.
