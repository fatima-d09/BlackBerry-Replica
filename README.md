# BlackBerry-Replica
A replica of Black Berry keyboard phone in the browser, made with React.

## Put it on GitHub Pages
1. Upload `index.html` and `app.jsx` to the root of a GitHub repo.
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. Open <a href="https://fatima-d09.github.io/BlackBerry-Replica/">https://fatima-d09.github.io/BlackBerry-Replica/</a>

## Run it on your computer
Double-clicking `index.html` won't work because the browser blocks loading `app.jsx` from a file.
Run a small server in the folder instead:

    python -m http.server

Then open http://localhost:8000

## Controls
- Trackpad: swipe to move, click to select (arrow keys + Enter)
- Green key: phone / answer
- Red key: hang up / home
- Menu (Tab), Back (Esc)
- alt types the small numbers and symbols
